## Konvenciók / döntések
- Ismétlődő generikus címek (A konvenció): "<cím> - <irányító fejezet>" (pl. "Power supply - PROFIBUS® PA (output code W)",
  "Indication - 1-5 Vdc HART® low power (output code M)", "Power module - Wireless (output code X)" vs.
  "Power module - Physical specifications", "Note - PROFIBUS® PA (output code W)", "Note - Wireless (output code X)");
  a hőmérséklet-alfejezetek: "Ambient - Temperature limits", "Storage - Temperature limits", "Process - Temperature limits".
  Az irányító feltétel 2. szegmensként is szerepel. Egyedi címek (pl. "Wireless radio (internal antenna, WP5 option)",
  "Overpressure limits", "Damping") utótag nélkül.
- A FF-blokkok (p. 85) a p. 83-as "FOUNDATION™ Fieldbus (output code F)" fejezet alá tartoznak → ez a 2. szegmens.
  A "Wireless (output code X)" és "Overpressure limits" az Azure-ban sima szövegsor, a renderen fejezetcím.
- A Physical specifications nem feltétel, nem ismétlem; a "Transmitter process-wetted parts" / "Non-wetted parts"
  fejezetcímet 2. szegmensként tettem be (nedvesített vs. nem nedvesített feltétel).
- Táblázatcella-lábjegyzetjelek (Table 6, Table 5) az adott sor/oszlop szegmensébe kerültek, az értékcella jelei is
  a sorcímke után (pl. "Inert fill sensor [fn 1] [fn 4] [fn 5] [fn 6]").
- Table 6: a "With Option Code BR6, coplanar/traditional flange" sorok (3051CD/CG/CF/CA) a renderen az Inert sor után,
  azonos szinten állnak; nem egyértelmű, melyik töltethez tartoznak, ezért közvetlenül a modellcsoport alá tettem
  (töltet-szegmens nélkül). A 3051T "With Option Code BR6" sorát szintén töltet nélkül. A "With coplanar/traditional/
  level flange / 305 manifold" sorokat a "Silicone fill sensor [fn 1]" (érték: N/A) alá soroltam.
- Table 4 második (cím nélküli) Azure-táblázata a renderen ugyanaz a Table 4 (DIN sorok + 248 °F sor) → azonos első szegmens.
  A "At 100 °F (38 ℃) …" és "At 248 °F (120 ℃) …" sorok teljes szövegként és °F/°C rekordként is szerepelnek.
- Process isolating diaphragms táblázat (cím nélkül) → "Process isolating diaphragms - table 1"; a "•" cellákat
  "Available" értékkel rögzítettem (a • jelentése: elérhető), az N/A cellák "N/A".
- Table 7 3051L cellái: érték "Table 8" (hivatkozás, szó szerint).
- Lábjegyzet p. 86: a dokumentum "7." számú lábjegyzete (Power module élettartam) → "[fn 7]" / "Power module - Wireless (output code X) | footnote 7"
  (a nyomtatott számot megtartottam).
- Mértékegységek: a ℃ / °℃ / ºF jeleket unit-ban "°C" / "°F" formára egységesítettem (a renderen °C / °F);
  szabad szöveges értékekben (lábjegyzetek) az Azure-szöveg változatlan (℃, º). A "- 40 - +185" típusú tartományokat
  szóköz nélkül "-40 - +185" alakban írtam; ahol "to" volt nyomtatva ("-40 to +80", "-40 to +149"), azt megtartottam.
- Lista-felsorolások (flanges and adapters, bolts) bullet-fejjel kaptak külön szegmenst, hogy az útvonal egyedi legyen.
- Kihagyva: oldalfej/láb, a "Material selection" első (marketing) mondata.
